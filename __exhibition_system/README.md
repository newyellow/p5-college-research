# 展演系統操作手冊 (Exhibition System Guide)

這份文件是給現場工作人員的操作指南。本系統用於控制與展示 p5.js 學院的研究作品。

簡單來說，這個系統分為兩部分：
1. **主控電腦 (Server)**：負責控制要播放什麼作品，並顯示「當前」的作品。
2. **展示電腦 (Client)**：(選用) 如果現場有其他電腦，它們會接收主控電腦的指令，播放「上一件」作品。

---

## 第一步：環境準備 (只需做一次)

在開始之前，電腦必須安裝 **Node.js** 這個軟體，它是讓系統運作的引擎。

1. **下載 Node.js**  
   請至 [Node.js 官網](https://nodejs.org/) 下載並安裝 "LTS" 版本 (建議 v16 或以上)。安裝過程一直按「下一步」即可。

2. **安裝系統工具**  
   打開電腦的「終端機」(Terminal 或 PowerShell)，進入到本資料夾 `__exhibition_system`，然後輸入以下指令並按下 Enter：

   ```bash
   npm install
   ```

   看到跑完一堆文字並且沒有出現紅色錯誤，就代表準備完成了。

---

## 第二步：每日開機流程

### 1. 啟動主控電腦 (Main Computer)
這台電腦負責控制整個展場。

1. 打開終端機，進入 `__exhibition_system` 資料夾。
2. 輸入以下指令並按 Enter：
   ```bash
   npm start
   ```
3. **系統會自動打開瀏覽器視窗**：
   - 一個是 **控制台 (Control Panel)**：用來選作品的。
   - 一個是 **展示畫面 (Display)**：用來全螢幕播放作品的。
   
   *請勿關閉這些黑色背景的終端機視窗，關掉系統就會停止。*

### 2. 啟動展示電腦 (Client Computers)
*如果現場只有一台電腦，請跳過此步驟。*

若有其他電腦負責延伸展示，請在那些電腦上執行：

1. 打開終端機，進入 `__exhibition_system` 資料夾。
2. 輸入以下指令並按 Enter：
   ```bash
   npm run client
   ```
3. 電腦會自動打開瀏覽器，並等待主控電腦傳送作品過來。

---

## 第三步：如何操作

### 切換作品
在 **主控電腦** 的「控制台」畫面中：
1. 您可以看到一些調整參數的拉桿 (Sliders)。
2. 調整好後，按下 **"Pick Random Artwork" (隨機抽選)** 按鈕。
3. **主控電腦** 會立刻開始播放新抽選的作品。
4. 同時，原本正在播放的作品會被「推」到其他的 **展示電腦** 上播放。

這設計是為了讓展場有多個螢幕時，可以同時呈現「現在的作品」與「過去的作品」。

## 常見問題與故障排除

**Q: 視窗位置跑掉了或是沒有全螢幕？**  
A: 請檢查 `configs/screenConfig.json` (主控端) 或 `configs/clientConfig.json` (展示端) 裡面的設定。通常是因為螢幕排列順序改變了。
最簡單的方法是手動把視窗拖到正確的螢幕並按 F11 全螢幕。

**Q: 系統卡住了怎麼辦？**  
A: 
1. 把所有跳出來的瀏覽器視窗關閉。
2. 到黑色的終端機視窗，按下 `Ctrl + C` 來停止程式。
3. 重新輸入 `npm start` (主控端) 或 `npm run client` (展示端) 重新啟動。

**Q: 新增的作品沒有出現？**  
A: 系統只會在啟動時讀取作品清單。如果您剛剛加了新檔案，請依照上述步驟重新啟動系統。

---

## 給工程人員的設定檔說明 (非必要勿動)

- `configs/screenConfig.json`: 設定主機要開幾個視窗、在哪個螢幕。
- `configs/clientConfig.json`: 設定展示機要連去哪台主機 (IP)、開幾個視窗。
- `configs/artworks/`: 這裡面是每個作品的設定檔。
